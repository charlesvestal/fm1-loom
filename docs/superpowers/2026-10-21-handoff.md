## Things learned

- The host's tests that build the synth need NTRK + 1 parameter rows: the synth reads the conductor's row
  (SY_GLFO_TRK) for the shared LFO.
- Scripts that count SELECT turns through GLO's pages or a list's rows break when a page or a row is added
  (pages.xy, autosave_off.xy, weavepage.xy, edits.xy): count from the end (`turn SELECT 30`) where possible.
- The device's libc has no memmove.
