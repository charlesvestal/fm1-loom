## How we work (learned this session)

- **Before installing on the FM-1**: ask; take ~/.fm1-device-lock; press SAVE, back up (`base/tools/fm1_backup.py
  backup build/demos/device/user-HHMM.loom8 --magic LM8B`), install, **check the project loaded** (tempo, scene) before
  letting go — a load failure plus autosave can overwrite the slot. Restore: `fm1_backup.py restore FILE --yes`, then
  SEL on the FM-1 (`fm1_remote.py tap SEL` once the tool says "received and checked"; don't poll the screen meanwhile:
  it answers "no").
- Other sessions flash the FM-1 too: a firmware that writes 0x97000+ (another firmware's data, a bigger app slot) erases
  LOOM-8's projects; the user said no backup routine is needed for that.
- Agents share the worktree: **never `git commit -a`** (it swept an agent's uncommitted work into a spec commit);
  commit `-- paths`. Builds collide: one building agent at a time (or build in a copy: `git archive` + base/ rsync).
- The user's taste for the UI: a reason for every label; no misleading shortcuts; mod pages edit, parameter pages
  play; KrisGelero is not credited.
