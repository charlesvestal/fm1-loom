# User feedback, 2026-10-21

Triage of the testers' points. Sizes: S = an hour or so, M = a day-ish, L = several days / a format change.
Status: [ ] open, [x] done, [-] won't do.

## A. Bugs (fix)

- [x] **A1 Clearing a scene always says "scene in use"** (S). The action asks "CLEAR SCENE N? (it is playing)" for the
  current scene, then `act_clear_scene` refuses exactly the current scene (ui.c:2301-2315). Let it clear the current one.
- [x] **A2 Song slot insert/delete while playing** (S). `slot[]` shifts, `seq.song_pos` doesn't (ui.c:2511-2538,
  seq.c:1044): a bar repeats or skips, Song highlights the wrong slot. Adjust song_pos when the edit is at/before it.
- [~] **A3 Clear notes / clear locks** (S). Clear notes leaves the lock lanes behind; clear locks has no undo and also
  wipes the kit tune lanes, which aren't locks (ui.c:2090-2100, pattern.c:127). **Fixed those; the report itself
  not reproduced (stopped or playing, synth or kit): need the tester's steps.**
- [x] **A4 Pattern copy/paste scope** (S-M). Copies only `tpat_t`: locks and tune lanes stay with the destination;
  pastes across track kinds (MIDI 60 on a kit = sounds 3-6). Copy lanes with the pattern; refuse (or convert) across kinds.
- [x] **A5 Kit page REC strip** (S). Shown on kit pages while stopped, but filled vs empty are two near-identical greys
  (`K_PANEL2` vs `K_PANEL`, pages.c:4026); and kit keys only add sounds. Use the track tint like Steps; check the
  "didn't record on the drum track" report in the simulator.
- [x] **A6 Sample engine clicks on overlapping mono notes** (S-M). Retrigger jumps the play position to the start with
  no fade (synth.c:1411); slice already has a 64-sample switch fade (`SL_SWITCH`). Port it.
- [x] **A7 Line drawing notches** (S). `cv_linef` is half-open and swaps ends for right-to-left lines, so a polyline can
  miss a shared vertex; no joints/caps (gfx_loom.c:134-172, pages.c:628). Dot each joint, or close the range.
- [x] **A8 Slices sound short** (S). 8 slices = 2 steps a slice, but note length defaults to half a step and release to
  ~18 ms, so a slice plays about a quarter of itself. Slice tracks: let the slice play to its end (gate), or default
  longer note length/release.
- [x] **A9 Saving: "no slot" while a slot is shown** (S). SAVE says "NO SLOT YET / HOME, SEL: SAVE TO" (ui.c:1537). **→ decided: save to the shown slot, ask only when there is none.**
  Either don't show a slot, or save to the shown one without asking.
- [x] **A10 Ducking makes the kick quieter** (M). Master PUMP ducks the whole mix including the kick that triggers it; **→ decided: the trigger track stays out of the duck; measure the RAM.**
  only the 12 ms rise lets the attack through (fx.c). Exclude the trigger track from the duck (needs a dry bus for it).
- [-] **A11 Clicks on USB-C audio** (?). The ring-underrun breakups were fixed with `FM1B_UAC_DEEP`; real dropouts are **→ dropped: audio out of the FM-1, recent build, not reproduced.**
  CPU load. Need the tester's details (which direction, project, released build?).
