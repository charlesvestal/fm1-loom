LOOM-8 USB test (0.11.99)

A test build for issue #7: the USB audio input not showing up on macOS 13–15. It is LOOM-8's current development version with one change: the USB MIDI interface comes after the audio streaming interface. It is not a release.

Back up your projects first, on the backup page: the test build is LOOM-8's development version, with a new way of storing projects.

Install the test build (Chrome or Edge, over USB).

Then look for LOOM-8 FM-1 as an audio input in System Settings → Sound and in Audio MIDI Setup, try recording from it, and check MIDI still works. Please report on the issue, with your macOS version.

To go back, install LOOM-8 from the normal install page, then restore your backup. Projects saved with the test build may not load in 0.11.
