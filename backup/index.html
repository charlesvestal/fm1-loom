Back up LOOM-8

Save what LOOM-8 keeps to a file on this computer, and load them back later. Connect the FM-1 with a USB cable. This page works in Chrome or Edge, and there is nothing to install.

Plug the FM-1 running LOOM-8 into this computer with a USB cable.

Is the FM-1 under another name?

A computer can show an FM-1's port under another device's name (a Mac remembers names by USB socket). This page asks only the ports with an FM-1's usual names by itself. If your FM-1 is in this list, press Try on it.

    Back up

    This saves everything to a .loom8 file. That includes the three projects, the user presets and the samples. LOOM-8 can keep playing. If you have changes that aren't saved yet, stop LOOM-8 first so they go in the file too.

    Restore

    This puts a backup back on LOOM-8, and it replaces everything there. Stop LOOM-8 first. LOOM-8 checks the whole file before anything changes. Then its screen asks RESTORE FROM USB? Press SEL on the FM-1 to restore, or HOME to keep what you have.

    • A backup doesn't hold the button calibration: it belongs to the FM-1.
    • The samples go in the file too. A restore sends them after LOOM-8 has said yes on its screen, which takes about 20 seconds more. An older backup has no samples, so a restore from it leaves the samples as they are.
    • A cut cable or a damaged file changes nothing. Even a power cut during the write leaves either what was there or the backup, never a mix.
    • The browser asks once for permission to use MIDI with SysEx. Allow it, and close other apps that use the FM-1's MIDI first.
    • You can also do it from a terminal, in LOOM-8's repository: python3 base/tools/fm1_backup.py for the projects and presets (the same files: it leaves their samples alone), and python3 tools/loom_samples.py backup / restore for the samples (its restore takes this page's files too).
